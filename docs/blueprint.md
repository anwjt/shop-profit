# **App Name**: Shop Profit Calc

## Core Features:

- Input Parameters: Accept user input for cost price, desired profit margin, additional shipping costs, and platform fees.
- Price Calculation: Calculate the final selling price to avoid losses, incorporating all provided parameters.
- Price Display: Display the calculated selling price prominently.
- Price Suggestion: Suggest a possible final sale price that rounds up to 'psychological' pricing tiers (like prices ending in .99) by calling an LLM with the 'tool' instruction to reason whether to include it in the response.

## Style Guidelines:

- Primary color: Saturated blue (#4285F4) to represent trust and efficiency in financial calculations.
- Background color: Light blue (#E3F2FD), a desaturated variant of the primary to maintain focus on the input fields and calculated price.
- Accent color: Yellow (#FFCA28) to highlight the calculated selling price and important action buttons.
- Body and headline font: 'PT Sans', a humanist sans-serif to make the UI feel modern but approachable and readable.
- Use simple, geometric icons for inputs and actions.
- Ensure a clear, linear flow from input fields to the displayed selling price.
